Why RawTrail

An independent record

Recorded by macOS, not reported by the agent, so you can check one against the other.

Search by session

Find any agent session across your Macs, then open the processes, file changes and connections behind it.

Yours to run

Self-hosted and MIT licensed. Your data stays on your server.

How it works

  1. Record

    Extensions on each Mac watch processes, files and network connections, and link them to the agent session.

  2. Collect

    A small agent sends the events to your RawTrail server, and queues them if it is unreachable.

  3. Review

    Open the web UI to see each session as a process tree, with alerts when something looks wrong.

Also a macOS EDR

RawTrail is an endpoint detection and response system for macOS, so everything it records works for ordinary security investigation too.

  • Behavioral detections

    Rules for credential access, persistence and command and control.

  • MITRE ATT&CK

    Detections are mapped to ATT&CK techniques.

  • Application control

    Block software by hash, path, signing ID or team ID.
